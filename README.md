Software Developer, Ice Skater
--------------------------

* 🏡  I'm based in Warsaw,
* 💻  I'm currently working on [Insett](https://github.com/szytambsky/insett),
* 🔧  Maintainer of [Posbus](https://github.com/szytambsky/komunikacjalive),
* 🔭  But above all, learning everything Java related

I have been programming for some time now. My main interests are web applications from backend perspective. Currently, I spend most of my time in the JVM ecosystem. I draw my knowledge from online sources, documentations and books. For those who are also at the development road, from me I can recommend: "Microservices" - Chris Richardson, "Effective Java" - Bloch, Joshua. Recently, I have also been attending and trying to contribute to the local Java community: WJUG (Warsaw Java User Group) 

Currently developing a web application using a modular monolith architecture, with plans to evolve it towards a microservices based architecture inspired by Chris Richardson’s Microservices Patterns.
The project focuses on deepening my understanding of distributed systems, including eventual consistency and the Saga pattern for managing distributed transactions. I am also exploring asynchronous communication and event driven architecture using Apache Kafka, as well as Elasticsearch for search capabilities and inverted index based data retrieval.
Additionally, I aim to strengthen my DevOps skills by containerizing services and deploying the application with Kubernetes, with the long-term goal of releasing it to real world users.
